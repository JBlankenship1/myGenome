With all of our software and files ready, we can start sequencing
Run fastqc on both forward and reverse reads:
fastqc Bc395_1.fq.gz Bc395_2.fq.gz -o ~/sequences

Will return .html files, that can be downloaded and opened in a web browser to view.
This can be done with scp:
scp jrbl245@jrbl245.cs.uky.edu:Bc395_1.fastqc.html .
scp jrbl245@jrbl245.cs.uky.edu:Bc395_2.fastqc.html .

Viewed html files include data on provided screenshots such as summary statistics and adaptor content.
We next need to run trimmomatic to trim off adaptor contamination. Documentation on trimmomatic:
http://www.usadellab.org/cms/uploads/supplementary/Trimmomatic/TrimmomaticManual_V0.32.pdf
java -jar trimmomatic-0.38.jar PE -threads 2 -phred33 -trimlog Br80_errorlog.txt Bc395_1.fq.gz 
Bc395_2.fq.gz Bc395_1_paired.fastq Bc395_2_paired.fastq ILLUMINACLIP:adaptors.fa:2:30:10
SLIDINGWINDOW:20:20 MINLEN:125

This will return four fastq files:
Bc395_1.fq.gz Bc395_2.fq.gz Bc395_1_paired.fastq Bc395_2_paired.fastq
With the paired reads including both the forward and reverse reads.
